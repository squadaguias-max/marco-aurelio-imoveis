# Marco Advocacia — Landing Page de Usucapião

Landing page em React e Vite para análise inicial de imóveis urbanos e rurais sem regularização.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação de produção

```bash
npm run lint
npm run build
```

## Conteúdo e contatos

Os dados centrais ficam em `landing.data.json`. O formulário usa o WhatsApp quando um número completo é configurado; enquanto o número estiver ausente, abre o aplicativo de e-mail com os dados preenchidos para revisão antes do envio.

Antes da publicação, confirmar o número completo do WhatsApp e a aprovação final do conteúdo.
